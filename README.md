Brain tumor segmentation and classification from multi-modal Magnetic Resonance Imaging (MRI) is a critical yet challenging task in clinical neuro-oncology.The framework introduces four key novelties: (1) Prototype Contrastive Learning for structured latent representations; (2) Cross-Attention Skip Fusion for selective feature integration; (3) Dual Explainability via Grad-CAM and Attention Rollout; and (4) a Hybrid Loss combining Dice, Cross-Entropy, Boundary, and Contrastive terms. The framework achieves best Whole Tumour Dice of 0.801, Tumour Core Dice of 0.83, and Grade Classification Accuracy of 1.00.
